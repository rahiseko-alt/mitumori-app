# 申し送りはプラットフォームのコメント機能ではなく `db` に置く

確定した案件に営業が書き残すのは、ページへの注釈ではなく**この見積についての申し送り**である。
「客はこの項目を渋っていた」のような、技術者が読むべき情報が入る。プラットフォームの
コメント機能に置くと claude.ai の外枠にスレッドが出るだけで、**CSV にも書面にも出ず、
後から読み戻すこともできない**。よって案件のデータとして `db` に持ち、自前で表示する。

## Considered Options

- **プラットフォームのコメント機能**: 実装は軽く、`openComposer({element})` で特定の要素にも
  紐付けられる。だが「スレッドを描くのは claude.ai の外枠で、ページ内に自前の一覧を作ることは
  禁じられている」ため、申し送りを見積の一部として扱えない。

## Consequences

- 申し送りは確定後も書けるので、確定した案件のパスのうち申し送りだけは `interact` が
  書ける場所に置く。見積の中身は `admin` のまま動かさない。
- `comments` 能力を宣言しないため、そのページを組織内部限定にする制約もかからない。
  ただし顧客には共有しない方針（ADR 0002）は変わらない。
