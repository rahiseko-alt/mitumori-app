# 営業への渡し方

営業はスマートフォンの claude.ai から使います。そこからは、このリポジトリのファイルは
見えません。だから**手順と単価をプロジェクトに預ける**必要があります。

準備は技術者が1回やれば済みます。営業は招待されたプロジェクトを開くだけです。

## 技術者がやること（1回・15分）

### 1. プロジェクトを作る

claude.ai で新しいプロジェクトを作り、名前を「見積」などにします。

### 2. 指示を貼る

`.claude/skills/mitsumori-flow/project-instructions.md` を開き、**先頭のコメント行より
下をすべて**コピーして、プロジェクト設定の「指示」欄に貼ります。

### 3. ファイルを2つ添付する

同じフォルダの次の2つを、プロジェクトのファイルとして上げます。

- `price-table.md` — 96項目の単価
- `open-points.md` — 論点ごとの幅と、聞く順番

### 4. 営業を招待する

プロジェクトを営業と共有します。**営業ひとりひとりに Claude のアカウントが要ります。**

### 5. 動くことを確かめる

プロジェクトの中で、適当な商談メモを1つ貼ってみてください。

> 山陽建設さん。現場の写真を職人がスマホで撮って、事務所が確認する。いまはLINEで送って
> きて事務所が手で台帳に貼っている。月300件くらい。協力会社も10社くらい使う。トンネル内は
> 電波が入らない。所長が承認してから施主に提出。写真は工事ごとにまとめてPDFで出したい。
> 会計とはつながなくていい。

「こういう製品で合っていますか」と幅つきの金額（1,305〜3,315千円あたり）が返ってくれば
正しく動いています。金額がまるで違う、または項目名が価格表にないものだったら、
指示かファイルの貼り忘れです。

## 営業がやること

### 商談の前

準備は要りません。プロジェクトを開けば始められます。

### 商談の中

**1. 聞く。** いつもどおり顧客の話を聞きます。この間、Claude は使いません。

**2. メモを渡す。** 聞き終えたら、聞いた内容をチャットに入れます。キーボードのマイク
（音声入力）で話しても、打ってもかまいません。箇条書きでなくてよく、話し言葉のままで
かまいません。最後に「まとめて」と書きます。

**3. 見せる。** 「こういう製品で合っていますか」と金額が返ってきます。画面を顧客に見せて、
言葉が合っているか確かめます。違っていたらそのまま言えば直ります。

**4. 幅を説明する。** 金額には幅があります。「まだ決まっていないことが◯件あるので、
この幅です。決まるたびに上限が下がります」と伝えてください。**真ん中の金額を言っては
いけません。** 真ん中に根拠はありません。

**5. 決められるものから決める。** 「これが決まると上限が下がります」に並んでいるものを、
上から聞いていきます。上のものほど金額が動きます。決まったぶんだけ幅が縮みます。

**6. 続きは次回。** その場で決まらなくてかまいません。次の商談でメモを足せば、そこから
続きます。

### 商談のあと

技術者へは、チャットの内容をそのまま渡してください。整理しなおす必要はありません。

## 営業が守ること

- **価格表にない金額を顧客に言わない。** Claude が「価格表にない項目です」と返したら、
  その場で金額を答えず「持ち帰って確認します」と言ってください。
- **幅を勝手に狭めない。** 「もう少し安くなりませんか」と言われても、決まっていない論点が
  残っている限り幅は縮みません。縮めるには論点を決めるしかありません。これは値引きの話
  ではなく、まだ何を作るか決まっていないという話です。
- **確定は顧客が承認してから。** 確定すると金額は動かせなくなります。取り消せるのは
  技術者だけです。

## 単価を変えたとき（技術者）

`catalog.js` を直したら、必ず両方を作り直してプロジェクトのファイルを差し替えます。

```
node scripts/build-price-table.js
node scripts/build-open-points.js
node scripts/build-project-instructions.js
node --test tests/*.test.js
```

**差し替えを忘れると、営業は古い単価を顧客に言い続けます。** テストは表とカタログの
ずれを検出しますが、プロジェクトに上げたファイルが古いことまでは分かりません。

## この形の限界

- **音声を丸ごと預かることはできません。** チャットのマイクは1通ぶんの音声入力です。
  1時間の商談を録りっぱなしにする用途には向きません。録音を残したい場合は、端末の
  録音アプリを別に使ってください。
- **Claude が合計を間違える可能性は残ります。** 指示で「項目を並べてから足す」と
  定めていますが、計算そのものを止める仕組みはありません。金額が前回と大きく違うときは、
  営業が並んだ項目を見て気づけるようにしています。
- **項目ごとの明細は顧客に出しません。** 顧客へは分類10件の小計と総額までです。
  求められたときだけ出してください。
