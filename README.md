# 開発見積ナビ（独立リポジトリ版）

非エンジニアが初回商談で「何を実現したいか」を聞き取り、次回以降の商談で機能・前提条件・概算費用を確認するためのブラウザアプリです。工事管理アプリ本体ではなく、開発範囲を合意するための見積ナビゲーションツールです。

## 動作環境

- 実行：Chrome / Edge などの現行ブラウザ
- 配布：このフォルダを静的ファイルとして配信できる環境
- 実行時の外部ライブラリ・npm install・ビルド手順：不要
- テスト：Node.js 20 以降（`node --test`）

## 起動方法

ZIPを展開したフォルダで、次を実行します。

```powershell
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。Pythonがない場合は、任意の静的HTTPサーバーで同じフォルダを公開できます。単純に `index.html` を直接開いても基本操作はできますが、保存・読込やブラウザ制限を避けるためHTTPサーバー起動を推奨します。

## 使い方

### 1ページ目：初回ヒアリング

顧客の要望を、技術用語ではなく「通信がなくても入力したい」「写真を関係者へ共有したい」などの実現したい状態で選択します。回答に応じて、2ページ目で確認すべき候補が自動的に選ばれます。自由記述・案件情報も入力できます。

### 2ページ目：機能別見積もり

1カラムの縦型ツリーを上から確認します。項目名は実現したいこと、その右側にエンジニア向けの技術名を表示します。

- レ点：採用する項目。空欄：採用しない項目
- 親項目を外すと配下をまとめて外す
- 依存する項目は自動追加され、他項目から参照されている間は鍵マークで保持
- 鍵マークの横に、保持の原因となる関連項目番号を表示
- 各項目の固定単価・規模・参考作業時間・担当区分を確認できる
- DATABANK「価格表 機能別マスタ」（2026年6月29日）に直接対応する34項目は原本単価を維持
- 非対応62項目は既存単価との規模・難易度・再利用性の比較で補完査定し、原本単価と明確に区別
- 項目を押すと、値付けの「根拠」と「意図」を確認でき、CSVにも出力できる

画面下部には選択項目の内訳、依存関係ツリー、合計金額が表示されます。JSON保存・確認付きJSON読込・合計行付きCSV出力・印刷（PDF保存）が利用できます。表示金額は消費税別の参考概算です。

案件内容は初期状態では端末に自動保存されません。「この端末に自動保存」を明示的に有効にした場合だけブラウザへ保存されます。共有PCではオフのまま使用し、引継ぎには「案件保存」でダウンロードするJSONを利用してください。

## 計算式

同じ依存項目は重複計上しません。工数は期間検討用の参考値で、金額計算には使用しません。

```text
概算合計     = 選択された項目（依存項目を含む）の適用単価合計
年間保守目安 = 概算合計 × 10%（別途）
```

標準QA一式に含まれる単体・結合・画面操作テストは二重計上しません。外部API連携基盤は単独選択時30万円、他機能から自動追加されるときは共通基盤配賦12万円です。

固定単価はDATABANK内で比較検討するための相対参考値で、市場総額ではありません。正式見積では対象範囲・既存資料・連携先・確認レベルをヒアリングして校正してください。表示金額は契約金額を保証しません。査定方法と公開資料は [PRICING_RATIONALE.md](PRICING_RATIONALE.md) に記載しています。

## カタログの拡張

案件固有の項目は画面から追加できます。`catalog.js` の項目定義を編集する場合は、項目番号（`id`）、技術名（`name`）、実現したいことの表示名（`plainName`）、固定単価（`fixedPrice`）、規模（`priceSize`）、参考作業時間（`hours`）、依存項目（`dependencies`）を合わせて更新してください。共有依存は複数項目から参照させても1回だけ計上されます。

## テスト

```powershell
node --test tests/*.test.js
```

親・中間・末端の解除、共有依存の保持、全96項目の正の単独価格、原本34項目の維持、査定62項目、QA内包、API基盤配賦、代表5プリセットの金額、画面・CSVの根拠表示を検証します。
